# Екранни снимки за Google Play

1080×1920 (9:16, телефон), PNG 24-bit RGB без алфа канал (Play отхвърля прозрачност).
Рамкирани са с `tools/play_screenshots.py`: лента с кратък надпис (Cormorant Garamond
върху бордо) и екранът под нея. Суровите екрани идват от `PlayScreenshotTest` в CI
(клон `screenshots`, файлове `play-*.png`); след промяна по външния вид:

```
git fetch origin screenshots
python3 tools/play_screenshots.py
```

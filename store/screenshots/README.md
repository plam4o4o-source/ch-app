# Екранни снимки за Google Play

Тук се поставят екранните снимки (PNG, 1080×2400 или подобно 9:16), направени
от `prodRelease` build срещу живия сайт chyavorec.org:

1. `01-home.png` — Начало
2. `02-catalog.png` — Каталог с резултати
3. `03-book.png` — Страница на книга
4. `04-news.png` — Новина
5. `05-events-calendar.png` — Събития (календар)
6. `06-card.png` — Читателска карта

Android Studio → Running Devices → „Take screenshot“, или
`adb exec-out screencap -p > 01-home.png`.
